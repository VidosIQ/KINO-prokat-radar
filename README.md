# Кинопульс — Кинопрокат России

Интерактивный дашборд кассы российских кинотеатров: топ-5 ЕАИС по сборам, зрители, доля лидера, различия с Kinometro и рейтинги разных источников. Скачать данные — Excel (.xlsx), пять листов: «Описание» со ссылкой на сайт и методикой, «Сборы», «Рейтинги», «Фонд кино PDF», «Сравнение источников». Названия фильмов выделены жирным; суммы и оценки — числа.

## Обновление

GitHub Actions проверяет [список отчётов Фонда кино](https://www.fond-kino.ru/pages/otraslevaa-analitika/) ежедневно в 07:23, 13:23 и 19:23 по Москве. GitHub может задерживать или пропускать schedule; точное время не гарантируется. Есть ручной запуск Actions → Update cinema dashboard → Run workflow.

Каждый период обновляется независимо: уикенд и неделя могут относиться к разным выпускам. Даты берутся из опубликованного отчёта, включая особые праздничные периоды. ЕАИС запрашивается по этим датам через штатный публичный запрос сайта. Проверяются порядок рейтинга и числовые поля. PDF используется только для общей кассы и своей выборки топ-12 по зрителям. Это не замена национального рейтинга по сборам.

При ошибке основного источника workflow завершается без публикации; последняя опубликованная страница остаётся доступной. Исходные ответы с SHA256 сохраняются в artifacts Actions на 14 дней. Manifest проверки — data/last-check.json. Нужен GitHub Actions Source в Settings → Pages.

## Различия источников

ЕАИС учитывает строки прокатных удостоверений; разные ПУ не объединяются. Разница = Kinometro − ЕАИС, процент от ЕАИС. Сравнивается Россия и только совпадающие даты. Если новый период Kinometro недоступен, остаётся подтверждённое историческое сравнение с явными датами. Недельная таблица Kinometro не подтверждена.

Film.ru и Критиканство проверяются по подтверждённым карточкам. Кинопоиск и IMDb сейчас сохраняются как датированные подтверждённые снимки: автоматический доступ к их оценкам не настроен. Это ограничение указано в интерфейсе; дата не подменяется временем запуска. Для новых фильмов без подтверждённой карточки показываются отсутствие оценки и поиск на Кинопоиске. Megacritic — без неподтверждённых баллов. Единого усреднённого рейтинга нет.

## Запуск локально

Python 3.12:

```sh
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/refresh.py
python scripts/validate.py
python -m http.server 8047 --directory site
```

`--force` повторно получает ЕАИС и PDF уже известного отчёта. Обычный запуск получает их при появлении новой ссылки отчёта; вторичные источники проверяются при каждом запуске. Все обращения — к публичным страницам, без ключей и обхода защит.

Шрифты: Manrope и Golos Text, локальные файлы и лицензии OFL в site/assets.
